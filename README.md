## 📖 Overview
This repository documents my **Week 3 project** in ethical hacking, focusing on **password cracking techniques**.  
The objective was to understand how attackers exploit weak passwords and how defenders can strengthen authentication systems.

⚠️ **Important Note:** All activities were performed **with proper authorization in a controlled lab environment**.  
This project was strictly educational and aimed at strengthening **ethical hacking skills**.

---

## 🛠️ Tools Used
- **John the Ripper (JTR)**  
  - CLI version for advanced cracking.  
  - Johnny GUI for simplified, beginner-friendly interface.  
- **NetworkWalks Online Password Cracking Tools**  
  - Cloud-based utilities for hash extraction and cracking.  
  - Useful for quick demonstrations and comparative analysis.  

---

## 🔍 Project Workflow
1. **Hash Extraction**  
   - Used Online Hash Extractor to convert a locked PDF into a crackable hash.  
   - Saved the hash in `hash1.txt` for JTR processing.  

2. **Password Cracking with JTR**  
   - Ran attacks using wordlists and brute force.  
   - Observed cracking speed and complexity handling.  

3. **Password Cracking with NetworkWalks Online Tools**  
   - Uploaded the same hash/file to NetworkWalks platform.  
   - Compared results with JTR for efficiency and convenience.  

4. **Analysis & Documentation**  
   - Recorded cracked passwords, time taken, and complexity.  
   - Compared offline vs. online approaches.  

---

## 📊 Key Insights
- **JTR Strengths:** Flexible, customizable, supports multiple hash types, ideal for labs.  
- **NetworkWalks Strengths:** Fast, cloud-based, minimal setup, great for demonstrations.  
- **Password Weaknesses:** Short or dictionary-based passwords are easily cracked.  
- **Best Practices:** Strong, unique, and complex passwords combined with **multi-factor authentication** are essential.
